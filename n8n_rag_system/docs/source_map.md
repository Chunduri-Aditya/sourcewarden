# Source Map

Primary source configuration lives in `config/sources.yaml`.

The first ingestion pass prioritizes official n8n documentation:

- n8n docs home and glossary.
- Build your first workflow and workflow concepts.
- Export and import workflows.
- Built-in node types and core nodes.
- HTTP Request, Webhook, Code, and Extract From File node docs.
- Advanced AI, RAG in n8n, AI Agent, LangChain concepts, and AI workflow tutorials.
- Google Sheets AI example as a workflow-template source.

The beginner RAG starts from official beginner-facing workflow and glossary pages. Add project-specific beginner notes later only if they are clearly marked as internal guidance.
